# Personal Academic Portfolio

> **Live Website:** [(https://aamini.netlify.app/)]

Welcome to the source code for my personal professional and academic website. 

Built as a digital hub to showcase my research, publications, background, and academic profile.

## Overview

This repository contains the Hugo-based source files powering my personal site, utilizing customized layouts and Markdown content management. It highlights:
* **Academic Background & CV:** Overview of my education, research roles, and affiliations.
* **Publications:** A curated list of research papers and conference contributions.
* **Projects & Research:** Documentation of ongoing work in particle accelerators, beam dynamics, and computational physics.

## Built With

* [Hugo](https://gohugo.io/) - The fast and flexible static site generator.
* [Wowchemy / Hugo Academic Theme](https://github.com/wowchemy/starter-hugo-academic) - The modular framework used for structuring academic portfolios.
